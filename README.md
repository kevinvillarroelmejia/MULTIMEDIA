## ▶️ Cómo ejecutar un proyecto

1. Clona el repositorio: `git clone https://github.com/kevinrashiid/DAM2-Programacion-Multimedia.git`
2. En Android Studio: **File → Open** y selecciona la carpeta del proyecto concreto (no la raíz del repo).
3. Espera a que sincronice Gradle y ejecuta en un emulador o dispositivo.
